Engineered an enterprise-grade attendance system replacing manual roll calls with live facial recognition using Dlib 128D embeddings and YOLOv8 person detection.

## Architecture

Architected a secure FastAPI backend with JWT Role-Based Access Control (RBAC) and a WebSocket-powered kiosk deployed via Docker and Vercel.
